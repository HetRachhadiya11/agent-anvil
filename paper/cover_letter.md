# Cover letter to the Editors of SoftwareX

Dear Editors,

Please consider the original software publication, “Agent Anvil:
Reproducible Trace Assertions and CI Regression Tests for Tool-Using Agents.”

Agent Anvil is a local Python harness that converts policies and observed
defects in tool-using language-model agents into executable regression tests.
Its contribution is a reusable software package combining stateful local tools,
strict scenario and trace schemas, deterministic response/state/trace
assertions, paired evaluation views, redacted CI artifacts, and a reproducible
analysis and annotation protocol. The manuscript deliberately does not present
the earlier deterministic fixture gap as evidence about real agents.

The submission package contains version 0.2.0 under the Apache License 2.0,
100 schema-valid scenarios across five domains, 14 passing automated tests,
five passing end-to-end smoke scenarios, security and contribution guidance,
and an adapter for provider-backed function-calling model runs. The complete
versioned source is available at:

https://github.com/HetRachhadiya11/agent-anvil/tree/03cae537e93c317048f2afccd70d6fe73253869e

The paper reports only executed software verification. It does not reuse the
earlier synthetic 100%-versus-30% fixture gap as evidence about real agents, and
it makes no unsupported claim about model performance. By submitting this
letter, I confirm that the manuscript has not been published or submitted to
another venue, that I approve the manuscript, and that I accept responsibility
for the code, factual claims, and disclosed use of AI assistance.

Thank you for your consideration.
